# AI网站克隆管道引擎 (ai-website-clone-pipeline)

> 此文档为Feature `ai-website-clone-pipeline` 的详细规格文档，与 `ai-website-clone-pipeline.yaml` 配套。
> YAML文件存结构化元数据，此文件存人类可读的完整描述。

## 概述

将任意目标网站反向工程为像素级完美副本的5阶段自动化管道。
支持13个AI IDE平台，一份源文件同步所有平台。

## 来源

AI Website Cloner Template (JCodesMore, GitHub)

## 产品映射

- 白泽技能集市
- 烛龙工程流
- 链客宝

## 核心能力

### Phase 1: 侦察

- 浏览器MCP截图 + 字体/颜色/图标全局提取
- 交互扫描（滚动/点击/悬停/响应式）
- 页面拓扑映射
- 输出: `docs/research/` 系列文档

### Phase 2: 基础

- 字体配置 + 全局CSS变量更新
- TypeScript类型 + SVG图标React组件
- 资产下载脚本
- 验证: `npm run build`通过

### Phase 3: 组件规格+并行构建

- per-component spec.md（精确CSS值+行为+内容）
- git worktree并行builder
- 每builder ≤150行spec内容
- 验证: `npx tsc --noEmit`通过

### Phase 4: 组装

- page.tsx导入所有组件
- 页面级交互实现
- 验证: build通过

### Phase 5: 视觉QA

- 原始站点vs克隆并排对比
- 逐section差异修复

## 触发条件

当用户说"克隆这个网站"、"复制这个页面"、"逆向工程这个URL"时加载

## 依赖

- 浏览器MCP工具（Chrome/Playwright/Puppeteer）
- Node.js 20+
- git worktree支持
