# 浏览器设计令牌自动提取 (browser-design-token-extractor)

> 此文档为Feature `browser-design-token-extractor` 的详细规格文档，与 `browser-design-token-extractor.yaml` 配套。

## 来源

AI Website Cloner Template (extract-design-tokens.js + DESIGN_TOKENS.md模板)

## 产品映射

- 䑏疏跨境助手
- 白泽控制台

## 核心能力

### 提取维度

1. 字体家族（多元素采样去重）
2. 颜色系统（主色/文字/背景/功能色）
3. 间距系统（推断4px基础单位）
4. 圆角系统（按钮/卡片/头像）
5. 阴影系统（卡片/悬浮/模态框）
6. 渐变系统（linear-gradient/radial-gradient）
7. 响应式断点

### 输出格式

shadcn/ui兼容的CSS变量映射 + 完整Token表格

## 触发条件

需要理解目标网站设计系统时
