# 组件规格驱动构建 (spec-driven-component-build)

> 此文档为Feature `spec-driven-component-build` 的详细规格文档，与 `spec-driven-component-build.yaml` 配套。

## 产品映射

- 烛龙工程流
- 链客宝
- AI数字名片

## 核心能力

### Spec文件模板

- DOM结构树
- 精确CSS值（来自getComputedStyle）
- 多状态行为（hover/scroll/click/responsive）
- 资产路径
- 实际文本内容

### 构建门禁

- 不写spec不派builder
- 单builder ≤150行spec
- 复杂section拆多个builder
- 每builder验证 `npx tsc --noEmit`
- merge后验证 `npm run build`

### git worktree并行

- 每个builder在独立worktree工作
- merge时白泽作为orchestrator解决冲突

## 触发条件

需要精确还原现有UI，不止"看起来像"
