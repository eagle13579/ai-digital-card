# 一键蒸馏搭建知识库 — 原子化 + Feature化 研究（v1.0.0）

> 来源: 抖音@在运动的AI小刘 「一键蒸馏搭建自己的知识库 #开启AI时代 #普…」
> 产出: 远程白泽 2026-08-06 | 归档: docs/ | 反哺: gaia_knowledge

## 一、视频主题还原（基于分享文本）

主题：**普通人用 AI「一键蒸馏」搭建自己的知识库**
- 蒸馏 = 用 LLM 把原始资料自动提炼为结构化知识（去噪、抽精华、分型）
- 一键 = 全流程 pipeline 化，零代码、零手工
- 核心价值：把「收藏从未停止，学习从未开始」变成「资料自动变成可检索、可复用的知识资产」

与盖娅体系同构验证：九步法（采集→提炼→反哺）即蒸馏管线的实现；记忆宫殿+五池=知识库形态。

## 二、原子化（方法论原子拆解）

| # | 原子 | 说明 | 我们现状 |
|:-:|:-----|:-----|:---------|
| A1 | 多源接入 | 文档/网页/视频字幕/笔记/对话 统一进料 | ✅ gaia_collect_raw（GitHub/arXiv/本地） |
| A2 | 自动清洗 | 去重、去噪、过滤短元数据、格式规范化 | ✅ 幂等 source_id + 内容长度过滤 |
| A3 | LLM 蒸馏 | 提炼结构化知识（标题/类型/洞察/可复用价值） | ✅ gaia_reflect 提炼 |
| A4 | 知识分型 | concept/pattern/insight/rule/preference 分类 | ✅ knowledge_type 六型 |
| A5 | 向量入库 | 语义向量化 + 标签 + 关联，可检索 | ✅ 全量向量化 4831 条 |
| A6 | 语义检索 | 自然语言召回（RAG 应用层） | ✅ gaia API 检索 |
| A7 | 持续进化 | 定期增量、去旧增新、复盘沉淀 | ✅ 九步法日更 + 飞轮 |
| A8 | 一键编排 | 以上全流程 pipeline 化，一条命令/一次触发 | ⚠️ 部分（分步脚本，未真正「一键」） |
| A9 | 安全过滤 | 敏感/隐私信息蒸馏前剔除 | ⚠️ 有基础过滤，无完整策略 |
| A10 | 成本分级 | 粗提炼用便宜模型，精提炼用好模型 | ❌ 未分级（全量同模型） |

**结论**：10 个原子中 7 个已有，3 个缺口（A8 一键化 / A9 安全 / A10 成本分级）。

## 三、Feature化（转化为功能特性，进 Feature 库）

### 军团侧（AI数智军团 / 盖娅）
- **F-LEG-01 一键蒸馏命令**：飞书发「蒸馏 <链接/路径>」→ 自动接入→清洗→提炼→入库→简报（补齐 A8）
- **F-LEG-02 成本分级蒸馏**：A10 —— 常规素材走快速模型，高价值素材走深度提炼
- **F-LEG-03 蒸馏质量门禁**：入库前自动校验（长度/重复/格式），不合格打回重炼
- **F-LEG-04 蒸馏源扩展**：A1 扩展支持 抖音/公众号/PDF/视频字幕/剪藏链接

### 产品侧（AI数智名片）
- **F-CARD-01 AI 知识蒸馏服务**：B 端客户上传资料 → 自动蒸馏成企业知识库 → 会员增值卖点（可直接对标视频里的"一键蒸馏"做产品化）
- **F-CARD-02 名片知识画像**：客户名片+资料蒸馏 → 生成客户知识画像（销售弹药库）

### 产品侧（链客宝）
- **F-CHAIN-01 内容资产化**：商家发布内容 → 蒸馏沉淀为可复用营销知识库
- **F-CHAIN-02 商品知识卡片**：商品资料一键蒸馏 → 销售话术/问答知识库

## 四、进化路径（优先级排序）

| 优先级 | 事项 | 工作量 | 收益 |
|:-:|:-----|:-----|:-----|
