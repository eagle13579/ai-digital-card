## 已修复问题汇总

### 修复1: app.js — 删除开发残留代码
**位置**: `miniapp/app.js` 第21-24行
**问题**: `setTimeout(() => { wx.reLaunch({ url: '/pages/login/index' }) }, 100)`
**后果**: 每次启动100ms后强制跳登录页，导致"闪退"。用户填表到一半被踢走，无法正常登录获取token。
**修复**: 删除这4行代码

### 修复2: 3个桥接文件 — require路径错误
**位置**: `utils/platform-bridge.js`、`ai-bridge.js`、`network-bridge.js`
**问题**: 用 `require('../../utils/mockService')` 引用同级目录文件
**后果**: 所有用到这些桥接文件的页面全部崩溃（platform/create/detail/list/manage，ai/chat/generate/insight/match/scan，network/graph等）
**修复**: 改为 `require('./mockService')`
